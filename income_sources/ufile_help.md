How to download the UFile PDF

1. Sign in to the UFile account that contains the return.
2. Open step 4, Tax Return. This opens the Tax Return - view or download page.
3. In the Family members row, select the person whose return you want to load.
4. Confirm that the page heading and return text show that person's name.
5. Click Taxpayer's copy, save PDF in the Guidance and diagnostics area.
6. Repeat steps 3 to 5 for each individual that you want to record.
7. Keep each person's name and tax year in the downloaded filename when possible.

Before saving the imported values, confirm that the selected person in this application is the same person shown by the PDF. The PDF is used only to preview values and is not stored by this application. If the PDF exposes a taxpayer name, the application blocks a mismatch. If it does not, verify the document yourself.
